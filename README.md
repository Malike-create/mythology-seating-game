\# Mythology Seating Game



A cozy educational puzzle game inspired by Kyrgyz and Turkic mythology.



\## Engine



Godot Engine 4.7.1



\## Current status



Early gameplay prototype.



\## Implemented



\- Data-driven creature resources

\- Nine mythological creatures

\- Directed creature relationships

\- Creature abilities

\- Happiness calculation

\- Linear and circular table support

\- Drag-and-drop seating

\- Per-creature emotional states

\- Data-driven level generation

\- Host objectives and level completion

\- Two prototype levels

\- PC
